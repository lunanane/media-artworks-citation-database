# Norman

**James Paterson**, 2017 · VR / AR / XR / Online / net art

Norman is an open-source animation tool written in JavaScript that runs in a web browser and lets the user draw frame-by-frame animation in 3D space with VR controllers. One mode creates a new frame and advances the timeline each time the user makes a mark. The tool was made with support from Google Creative Lab, and its animations could also be viewed in a browser.

## In their words

> In 2017 I created a custom animation tool—for myself. A tool to enable and facilitate my imagination and flow.
>
> — James Paterson, [Prix Ars Electronica archive, catalogue text (Computer Animation, Honorary Mention 2018)](https://archive.aec.at/prix/236458/)

<sub>says · unsigned project text</sub>

> It makes the process of animating more like playing a musical instrument. For instance, one mode automatically creates new frames and advances through the timeline each time you make a mark. The user can get completely lost in the process of drawing through time and space, without having to manually control the time-line.
>
> — James Paterson, [Prix Ars Electronica archive, catalogue text](https://archive.aec.at/prix/236458/)

<sub>says · unsigned project text</sub>

> Norman is an experiment in building a medium and using that medium to create concrete works, at the same time.
>
> — James Paterson, [Prix Ars Electronica archive, catalogue text](https://archive.aec.at/prix/236458/)

<sub>says · unsigned project text</sub>

> I have always been fascinated by the idea of our imaginations finding their way out of our minds and into concrete reality. Until virtual reality I pursued that interest by developing imagery with drawing, animation and code. For ages I have been waiting for virtual reality to mature so that I can create and hang out in imaginary worlds. And, even more importantly, make and use tools to create within these worlds where the laws of physics and normality do not apply.
>
> — James Paterson, [British Council Voices magazine, 'How do virtual reality animators find communities and audiences?' (15 December 2017), Wayback Machine copy](https://web.archive.org/web/2020/https://www.britishcouncil.org/voices-magazine/how-do-virtual-reality-animators-find-communities-audiences)
