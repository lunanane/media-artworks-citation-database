# Mindscapes (series, Kinect installation)

**Fernando Velázquez**, 2012 · Projection / Sensor / interaction / Light

Part of the Mindscapes series (begun 2010), in which the artist explores the idea of landscape in relation to brain activity using custom programming algorithms. In the 2012 solo show at Zipper Galeria, São Paulo, the darkened main room held an interactive installation where a 3D object formed in real time from ambient sound, while a Kinect infrared sensor mapped visitors' movements; projections covered a wall of about 30×65 feet. A neon piece reading "saudade" was shown in a transitional space, its lights vibrating at different frequencies that visitors could change with a dimmer.
