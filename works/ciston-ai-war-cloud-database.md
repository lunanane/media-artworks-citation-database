# AI War Cloud Database

**Sarah Ciston**, 2025 · Network / data / Online / net art / AI / generative

AI War Cloud Database is an online interactive database and visualisation (aiwar.cloud) that catalogues AI systems used to make automated decisions in warfare and maps where the same types of tools appear in commercial products such as iris scanners, chatbots, robot vacuums and mapping tools, along with the companies and governments involved. Users explore the material through network graphs, a searchable table and interactive stories; the project describes itself as both an interactive database and a tangible interactive installation. It received the S+T+ARTS Prize 2025 Grand Prize – Artistic Exploration and was shown in the S+T+ARTS Prize exhibition at Ars Electronica Festival 2025 in Linz.
