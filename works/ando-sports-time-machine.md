# Sports Time Machine

**Ryoko Ando, Hiroshi Inukai**, 2013 · Projection / Sensor / interaction / Performance / body

Sports Time Machine is a running lane in which people race against past running records projected onto the wall beside them - their own, those of family and friends, or animals whose runs were recorded at a local zoo - while each new run is saved as 3D data that players can manage on personal web pages. It was premiered in a vacant shop on a shopping street in Yamaguchi as part of YCAM's tenth-anniversary programme LIFE by MEDIA, running from 6 July to 1 December 2013, and was built with local citizens, engineers and sponsors. It received an Excellence Award in the Entertainment Division of the 17th Japan Media Arts Festival.
