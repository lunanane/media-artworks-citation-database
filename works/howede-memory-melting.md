# Memory Melting

**Saad Al-Howede**, 2025 · Light / Material / sculpture

Memory Melting is a light installation by Saad Al-Howede shown outside the stc Metro Station at Noor Riyadh 2025. It consists of three large illuminated forms made from discarded plastic toys collected from children around the world and fused together. Some sources describe the forms as spheres and others as oversized emoji shapes.
