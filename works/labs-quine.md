# Quine

**Larva Labs**, 2025 · AI / generative / Network / data / Text / print

Quine is a generative series of 497 blockchain-based artworks by Larva Labs (Matt Hall and John Watkinson), released on October 9, 2025 as the final Art Blocks Curated project. Each work's image contains the source code of the program that generates it, laid out on a grid; some outputs reproduce themselves exactly while others cycle through several generations, and collectors can choose which generation to display. At Zero 10, Art Basel Miami Beach 2025, all 497 works were shown in miniature on a vitrine table, with 10 shown as signed, framed works.
