# NoSearchBar

**Erik Anton Reinhardt**, 2022 · Online / net art / Network / data

NoSearchBar is a Chrome browser extension that removes the search bar from every website, including search engines such as google.com, and changes the browser's search provider so that searching from the URL address bar is disabled. A user who installs it can only reach content through what websites offer without a search, such as categories, sorting, forecasts and recommendation systems. It was made in the New Media Class at UdK Berlin (winter 2021) and received an Honorary Mention in Interactive Art+ at Prix Ars Electronica 2022.

>
